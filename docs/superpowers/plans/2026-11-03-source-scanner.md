# Constrained source-to-path generation plan

Issue #6, FR-008/009/021, WP-C07/C09, SRC-001/002, RST-009. Implement a macOS-only source traversal connected to `DurablePathIndex`, and retain the existing explicit-manifest API. Baseline is OpenGrok 1.14.20 commit `3ca9d73ebb0ddb5560fbc7631322d29d9fdc2ec3` and the public nested-Git corpus with raw original path coverage. The first mode supports only the verified default selection and a restricted, documented subset of safe ASCII directory/file names and C/Python/JS files; unsupported names, special files, symlinks and unreadable items fail the entire update. Recognized Git `.git` regular files/directories are ignored as the upstream enabled Git adapter does; this does not select repository ownership or implement history. Other SCM administrative names and configurable filters remain unsupported, never silently invented.

Walk relative to open directory descriptors, never follow links, reject type/identity changes and non-UTF8 paths, and enforce limits during enumeration. Capture directory/file metadata, rescan before commit, and reject any observed change. Because there is no exclusive operating-system lock on an arbitrary external source, callers must keep the tree and ancestors stable through scan and publication; the implementation cannot detect a change undone between observations or one after the last validation. Do not claim that this fulfills all Q8 consistency. No source content or reading snapshot is created, and no source file is written.

TDD integration tests: public source and nested Git add → scan → index → lookup → remove → rebuild → restart; default exclusions backed by upstream evidence; unsupported / permission / symlink / special file cases retain old generation; deterministic observed source mutation before commit rejects publication. Preserve raw original evidence and derive only bounded unordered path comparisons, never ranking. Run macOS correctness tests, evidence contracts, formatting, clippy, and planning package; do not run performance measurements or claim Linux/Windows support.
