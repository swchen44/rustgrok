# Local path host: bounded single-project Q8 slice

Issue #6; Q8/D12, D15/D16, FR-009/021, WP-C05/C07/C09, SRC-002/RST-009/REC-001. Existing direct CLI remains unchanged. A macOS-only foreground host owns one durable store lock and offers an explicitly development-only Unix-socket control adapter; this does not fix Q15, select a Web stack, expose LAN management, or implement OpenGrok HTTP/CLI compatibility.

The host binds one socket in an explicitly supplied private owner-only control directory, separate from source and store; verify absolute path components without following symlinks, store/source overlap and socket type/owner. Never unlink existing sockets on startup; remove only the socket identity this process created, after validation, on controlled shutdown. Require same-user peer and owner-only directory/socket; same-user malicious directory replacement is outside the documented trusted-root assumption. Fixed request/response bytes, read/write timeout, maximum concurrent clients, one writer, bounded job/status lifecycle; reject excess or malformed requests without truncating successful results.

Host owns `Arc<DurablePathIndex>`. IPC job starts a worker for a supplied expected generation; queries use snapshots concurrently and return the old successful generation while it builds. Finish as succeeded, failed, cancelled, or indeterminate. Publication-indeterminate or worker panic blocks future reads/writes until restart; no assumption that the old version survived. Cancel is cooperative; a late cancellation may lose. SIGINT/SIGTERM and stop stop admitting jobs, request cancellation and wait for workers; source I/O that never returns cannot be forcibly cancelled. The host retains the OS store lock until workers exit. Recovery opens only the validated current durable generation.

Feature-gated test seams only: pause/release, post-rename directory-sync failure, worker panic. Exercise fail-closed indeterminate/panic, shutdown signal and client bounds; default build must have no test seams. Keep original path-only/no-ranking scope and external source coordination. No benchmarks. Preserve native Mac results, source/license provenance and clean-clone planning package.
