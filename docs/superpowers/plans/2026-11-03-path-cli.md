# Restricted path CLI and subprocess e2e plan

Issues #6/#5; FR-008/009/021, WP-B01/C07/C09, SRC-001/002 and RST-009. Reference pinned OpenGrok 1.14.20 `IndexerTest.testIncrementalIndexAddRemoveFile` (source hash/provenance in existing upstream integration evidence). That test is a component integration case, not upstream CLI or browser e2e. Rustgrok's process/restart/cancellation and lock cases are additional requirements.

Add an unpublished `apps/grok-host` Cargo binary `rustgrok`; macOS-only, single project, foreground development interface, no JVM and no runtime Git requirement. Exact positional commands: `create PARENT NAME SOURCE PROJECT`, `index STORE SOURCE PROJECT EXPECTED` (`none` or positive generation), and `query STORE SOURCE PROJECT TERM`. Input paths are absolute UTF-8 paths, project is restricted lowercase ASCII, and the existing scanner subset and stable-source precondition apply. Explicit fixed development resource limits are documented, not a product capacity or SLO. JSON successes on stdout, JSON failures on stderr, defined nonzero error categories and SIGINT cancellation; no partial results. Query returns the library's candidate set with explicitly unspecified order, not original ranking or original CLI compatibility. All modes acquire the exclusive durable lock: another process's query returns Busy while indexing; Q8 concurrent search needs a later long-lived service. No search-over-content, SCM/history, Ctags, LAN/HTTP, UI or cross-project operations.

TDD subprocess e2e uses a generated source fixture with actual `git init` and a nested repository, source bytes or vetted public fixtures, no enterprise data. Assert index → query → add/remove → reindex → process exit/reopen → query; exact JSON fields and nonzero errors; unsupported/symlink/invalid/cancel preserve old durable generation and source bytes; corrupt store is rejected and never presented as no hits. A separately built feature-gated test-only pause at the real prepublication point permits deterministic SIGINT and a real competing query process while the index process owns the lock. The feature must be absent from default production build. Never claim this implements complete Q8, original UI/HTTP or ranking; reuse original raw path evidence only for bounded fixture projection.

Run tests serially with the existing Cargo target and locked/offline dependencies, native macOS; record source hashes, raw output, dependency licenses and limits, no performance tests. Check free space, fmt/clippy, default and fault-injection suites and package if safe; preserve prior evidence and report exact scope. Source/root mutation races still require external coordination and remain unverified across validation/publication. D19 requires necessary helpers to ship later; this path-only runtime invokes no Ctags/SCM helper.
