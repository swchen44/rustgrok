# Sparse FULL field scorer comparison

The three synthetic, publicly shareable source files here were indexed by the fixed OpenGrok 1.14.20 release using the recorded command and environment in result.json. `a.c` contains `main`, `b.c` is empty, and `c.c` has a different identifier. The original QueryBuilder/Lucene score probe reports maxDoc=6, FULL field document count N=2, n=1, sumTotalTermFreq=20, norm byte=10 and score `0x1.42a0e4p-2` for `/alpha/a.c`. The candidate output has three input documents, field N=2 and the same score float bits `3ea15072`. Raw original indexer and scorer output, source and index hashes, and the candidate JSON are preserved. This index is separate from the large-workload target and all recorded performance indexes.

`lucene-norm-table.txt` and `tantivy-norm-table.txt` are the 256 direct decoded values from the respective fixed libraries, and compare byte-for-byte; they do not establish norm encoding equality for all inputs. Java helper code and independent MIT Rust diagnostic wrapper are in the experiment directories. The original index is retained only in the local temporary path in result.json and is not committed; after deletion, reindexing need not reproduce its docIDs. No full product acceptance is claimed.
