# Local path host subprocess correctness

This native macOS development host is a single-project, path-only Q8 slice, not complete Q8, ranked search, OpenGrok HTTP/CLI, Web, SCM or installed-product acceptance. No performance measurement was made. Job/read concurrency follows user-confirmed Q8/D12; #6 tracks the implementation, and #5 tracks the public reference corpus. The host tests are independently authored MIT; the underlying path scanner and source-derived test retain their CDDL provenance, described in [scanner evidence](../source-scanner-2026-11-03/README.md).

[receipt.json](receipt.json) binds the base commit, actual commands, native environment, input hashes, raw stream hashes and observed post-run binary hashes. [Default stdout](default.stdout.txt) reports 9/9, with [stderr](default.stderr.txt); [test-hooks stdout](test-hooks.stdout.txt) reports 15/15, with [stderr](test-hooks.stderr.txt). These binary hashes are run observations; binary bytes are not retained as evidence or represented as bit-reproducible. If source changes later, the evidence contract uses the commit introducing this receipt; a shallow checkout missing that history cannot perform that check. Default tests verify test-mode environment settings and test-release command do not activate the feature-only hooks.

Real subprocess tests exercise host startup and indexing, queries during a controlled paused replacement, successful cutover, cancellation, unsupported source and stale expected generation, stop/restart and retained old/new generation as appropriate. Feature-gated injections exercise worker panic and post-rename directory-sync failure; both block further reads/writes until reopening. Another real subprocess receives SIGTERM during a paused build and exits after cancellation; SIGKILL at the paused precommit point leaves a stale socket and the prior durable generation, and the next host refuses to overwrite that socket. These are process-exit cases, not physical power-loss tests. Feature-only pause and fault controls are not deployable defaults.

IPC tests cover private owner-mode directory/socket checks, non-symlink paths, source/control overlap, refusal to overwrite an existing socket or file, overlong socket-path rejection under the 103-byte limit, same-user client connection, eight-handler cap, 4,096-byte request and 1 MiB response rejection, fragmented valid requests, slow-trickle whole-frame read deadline and a client timing out against a silent socket. The oversized-result test constructs a synthetic manifest through the index library to test framing; it does not claim source-scanner coverage. Timeout tests check protocol behavior rather than latency or throughput. Different-UID peer rejection and a saturated Unix connect backlog were not separately exercised; nonblocking connect/poll and peer-UID checks are implementation facts, not those missing runtime observations. Kernel or filesystem work is not forcibly interrupted.

The host uses a private Unix socket, not a LAN endpoint or frozen public API. Its same-user trusted-directory assumption does not protect against a malicious same-UID process replacing paths or impersonating a peer. Request/response deadlines and client count are bounded, but blocked filesystem or query execution may delay handler/worker termination; source mutations must be externally coordinated throughout indexing. Old generation remains available only within the described stable-source path component. The direct CLI still returns `busy` while the host holds the store; clients must use host-query. Linux, Windows, complete source-filter semantics, multi-project publication and full Q8 remain unverified. See the [host contract](../../../apps/grok-host/README.md).
